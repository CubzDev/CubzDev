## A little about me

I'm **Gene**, a self-taught software developer from Belgium. I started making websites and experimenting with programming around the age of 12. What began as a hobby grew into a passion for solving problems, understanding systems, and building software people can actually use.

I run **[CodeWrench](https://codewrench.org)**, where I work on websites, business applications, and custom digital solutions. I especially enjoy the work behind the interface: APIs, databases, integrations, automation, and figuring out how to make a complete system run reliably.

My experience isn't limited to sitting behind an editor. I've also worked in **technical analysis and logistics operations**, which has given me a useful perspective on how software affects real workflows. I like taking repetitive, messy, real-world processes and turning them into clear, efficient tools.

> I enjoy building the whole thing: from the first idea and database schema to deployment, monitoring, and the last annoying bug.

- **Main interests:** Full-stack engineering, backend development, workflow automation, infrastructure and AI-assisted development
- **Approach:** Practical, curious, self-directed, and always looking for a better way to do things
- **Outside of code:** Playing guitar, producing music, 3D printing, gaming, and tinkering with hardware

## How I like to work

- **Understand the actual problem first.** The best software starts with understanding the people and processes behind it.
- **Think end to end.** I like working across the UI, API, database, integrations, and deployment instead of treating them as unrelated pieces.
- **Automate the boring stuff.** If a repetitive task can be made reliable and simpler, I probably want to automate it.
- **Keep learning by building.** Side projects, experiments, and hands-on troubleshooting are a big part of how I've developed my skills.
